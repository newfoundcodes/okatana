# Official SDKs

Okatana provides official SDKs to help you seamlessly integrate with our platform across multiple languages and ecosystems. Each SDK is actively maintained and supports the complete Okatana API surface.

## Available SDKs

- **TypeScript / Node.js**: [typescript.okatana.newfoundcodes.com](https://typescript.okatana.newfoundcodes.com)
- **Java**: [java.okatana.newfoundcodes.com](https://java.okatana.newfoundcodes.com)
- **C# / .NET**: [csharp.okatana.newfoundcodes.com](https://csharp.okatana.newfoundcodes.com)
- **PHP**: [php.okatana.newfoundcodes.com](https://php.okatana.newfoundcodes.com)

Please consult the respective SDK documentation for installation instructions, configuration guides, and usage examples.
